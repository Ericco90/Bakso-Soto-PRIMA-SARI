# Website Bakso Soto Prima Sari

## Preview Website

![Preview Website](preview.png)

## Deskripsi

Landing page website untuk usaha kuliner Bakso dan Soto Prima Sari.

Website ini menampilkan informasi menu, galeri makanan, dan memudahkan pelanggan menemukan lokasi usaha.

## Fitur Website

- Landing page bisnis kuliner
- Galeri makanan
- Informasi menu
- Google Maps lokasi usaha
- Tombol WhatsApp pemesanan

## Teknologi yang digunakan

- HTML
- Tailwind CSS
- JavaScript
- GitHub Pages
